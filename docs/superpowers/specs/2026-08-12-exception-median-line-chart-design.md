# 예외 조건 중앙값 그래프 교체 설계

## 목적

Streamlit의 `4. 예외 조건` 탭에서 선택한 장르·연도의 초기 single과
초기 multi 중 어느 그룹의 실제 평가 수 중앙값이 높은지 한눈에 확인할
수 있도록 그래프를 교체한다.

## 변경 범위

- 기존 가로 덤벨 차트를 2점 선그래프로 교체한다.
- x축은 `초기 single`, `초기 multi` 순서로 고정한다.
- y축은 로그값이 아닌 실제 `rating_count` 중앙값을 사용한다.
- 두 중앙값을 선으로 연결하여 single에서 multi로 향하는 방향을 보여준다.
- single 점은 기존 파란색, multi 점은 기존 주황색을 사용한다.
- 각 점 위에 천 단위 구분 기호를 적용한 실제 중앙값을 표시한다.
- 그래프 제목에는 선택한 장르와 출시 연도를 표시한다.
- 그래프 옆의 예외 조건 상세표와 예외 조건 선정 방식은 변경하지 않는다.

## 데이터 흐름

1. 예외 조건 선택 결과인 `selected_row`를 사용한다.
2. `single_rating_count_median`과 `multi_rating_count_median`을 읽는다.
3. x좌표 `[0, 1]`에 두 값을 y값으로 배치한다.
4. 회색 연결선을 그린 뒤 그룹 색상의 점을 그린다.
5. 각 점 위에 실제 중앙값 라벨을 표시한다.

## 해석

- 선이 우하향하면 초기 single의 실제 평가 수 중앙값이 더 높다.
- 선이 우상향하면 초기 multi의 실제 평가 수 중앙값이 더 높다.
- 선이 수평에 가까우면 두 그룹의 실제 중앙값 차이가 작다.
- 이 그래프는 선택 조건의 중앙값 비교이며 인과관계를 의미하지 않는다.

## 경계 조건

- 두 값이 같아도 두 그룹의 점과 값 라벨을 표시한다.
- 값이 매우 작은 경우에도 y축 하단 여백을 두어 점이 잘리지 않게 한다.
- 큰 값은 축에서 자동으로 처리하고, 라벨에는 천 단위 구분 기호를 사용한다.

## 검증

- `4. 예외 조건` 탭이 예외 없이 렌더링되어야 한다.
- x축 라벨은 `초기 single`, `초기 multi` 순서여야 한다.
- y축은 `실제 평가 수 중앙값`이어야 한다.
- 기존 전체 Streamlit 탭 렌더링 테스트가 통과해야 한다.
